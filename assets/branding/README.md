# 应用图标

`launcher-reference.png` 是用户于 2026-09-25 指定的蓝色书页 / L 图标原图。彩色图标直接使用此图，未重新生成或重画。

应用资源位于 `app/src/main/res/drawable-nodpi/launcher_art.png`，内容与原图一致：

- Android 8+：前景使用原图与比例内边距，背景使用深蓝色；由桌面应用施加圆形或圆角遮罩。内边距使主要书页图案保留在可见区域，画布外侧白边位于常见遮罩之外。
- 旧版安卓：使用直接引用原图的图标资源。
- 主题图标：使用与书页 / L 图案对应的单色矢量轮廓，由系统配色，不再使用旧 LF 卡片图标。

此版本为 1.0.2（versionCode 3），沿用现有应用 ID 和签名，保留之前的离线语音修复。
