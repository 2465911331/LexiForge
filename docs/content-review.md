# 第一批内容修订

内置词书现在只有 18 个显式词条、24 个构词组件。删除旧版将 82 个模板机械套用 25 类词形变化的扩词程序，不再生成 commited、commiting、attractly、visibled 等内容。

## 内容边界

- 例句为本项目编写的教学例句，不宣称来自考试真题。
- 构词说明中的“联想”是助记提示，不代表单词的全部词义，也不是完整词源推导。
- `structure` 使用独立的 `-ure` 组件，不再错误绑定 `-ion`。
- `describe` 展示 `de- + scribe`，保留词尾 e。
- `sensitive` 和 `definition` 采用整体拼写训练，避免用不完整的部件假装能够拼出整个单词。
- 内置词条没有词频排序依据，因此统一标为“未分级”。

- https://www.etymonline.com/word/describe
- https://www.etymonline.com/word/sensitive

## 旧数据更新

启动时根据当前词书标识决定是否更新内置内容。内置词书在同一个 Room 事务中安装，保留相同 ID 的 18 个词条和保留组件的学习状态、阶段、复习时间；不再保留旧模板生成词和未采用的组件。重复启动不重置有效学习进度。已下载的外部词书不会在启动时被替换。

主动点击“恢复内置词书”仍按原产品行为重置到默认内容。多词书独立进度、导出备份以及一般数据库结构迁移不属于本批修改。

## 复习规则

- 未学内容：`lastReviewedAt == 0`。
- 已学且到期：`nextReviewAt` 不晚于当前时间，包括遗忘后处于阶段 0 的内容。兼容旧版把已学词的时间清零的情况，这些词重新进入待复习队列。
- 普通训练展示到期内容和新内容；“仅到期”模式只展示到期内容，允许空队列。
- 首次答对进入阶段 1，5 分钟后复习；随后依次为 30 分钟、12 小时、1 天、2 天、4 天、7 天、15 天。
- 答错回到阶段 0，5 分钟后重新复习；不因“当天已经练习”而排除。
- 提前自由练习或立即改正错题不会提升间隔复习阶段。
- 队列在被界面观察时每秒检查时间，回到页面时重新检查；不发送后台通知。
- 取消 20 词解锁门槛。移除会混用真实时间与模拟时间的“次日模拟”入口，时间边界由自动化测试覆盖。
