# 1.0.3：备份与数据保护过渡版

本批对应 [数据可靠性规划](data-safety-plan.md) 的第一批。数据库结构仍为版本 3；多词书并存与结构 3 → 4 的迁移尚未实现，切换词书仍是替换内容，但现在替换前会保存恢复点。

## 使用方法

1. 在现有 1.0.2 上覆盖安装此调试包，保留应用数据。打开“设置 → 备份与恢复”。
2. 点击“导出备份”，在系统文件选择器中选择保存位置。应用重新读取并校验成功后，才显示“备份成功”及最近已验证导出时间。
3. 点击“从文件恢复”，选取 `.lexiforge-backup` 文件，查看日期、词书、单词数、组件数和已练习数。
4. 点击“替换并恢复”才会写入；恢复将替换当前内容、学习状态和备份中的设置，不合并备份之后的记录。确认前可以取消。
5. 如需撤回替换、清空或恢复，点击“查看本机恢复点”，选择操作前的记录并查看预览。最多保留最近 3 份。本机恢复点会随卸载删除，因此请另外导出到应用外部。

备份未加密，包含词书和学习记录。它不包含 Google TTS 或其他系统引擎的语音包，换机后需重新安装音色并试听；引擎包名只恢复为首选项，实际发音仍走引擎发现和回退逻辑。

## 已实现的数据保护

- 导出内容包含当前词书 ID、词条内容、词根组件、已有阶段/时间/状态/组件复习次数，以及主题、动态配色、到期筛选、本地语音设置。旧版没有的作答历史不会伪造。
- 文件有独立格式版本、读取器版本、来源数据库版本、条数和 SHA-256 校验。校验值用于发现损坏，不用于证明来源身份。
- 校验失败、版本不支持、缺失组件、重复 ID、非法阶段/时间、未知 ZIP 成员和超大数据均在写入前拒绝。
- 首版为单词书读取器，拒绝超出其能力的备份。实际限制为压缩输入 20 MiB、解压数据 16 MiB、单词与组件各最多 20,000 项、单段文本 64 KiB；较规划中的暂定上限收紧，避免手机上一次解析占用过多内存。达到限制会停止并提示，不截断内容。
- 恢复预览记录当前状态指纹，提交前若内容、进度或可迁移设置变化，要求重新预览。恢复前创建并验证本机恢复点，失败就中止操作。
- 数据库替换在 Room 事务中完成。为处理旧结构的偏好设置与数据库分开保存，先原子写入待完成的数据包，再提交数据库和设置；冷启动会先完成已确认操作，再进入学习。
- 在数据库提交后被终止，下一次启动会继续完成该次替换。恢复点保留之前的状态；界面不会把这种情况误报为未发生任何变化。
- 恢复后重新建立学习界面状态，避免显示恢复前的词书名称和设置；恢复的内容不会被启动时的内置词书初始化覆盖。
- 写入统一协调，重置和词书替换使用事务。数据替换前排队的旧答案会被丢弃，防止写入新状态。
- 移除了无迁移路径时自动清库的配置。无法打开数据库时进入保护页，可重试或导出诊断；未知旧结构不会自动转换为空库。此页尚不提供损坏数据库的自动修复。
- 导出了 `app/schemas/com.example.data.AppDatabase/3.json`。结构身份为 `085574134c45d002745d1a9e734ab673`，已在此前交付的 1.0.2 APK 中核对到相同身份。本批版本号为 1.0.3 / versionCode 4。

## 验证与限制

本次构建成功，55 项自动化测试全部通过（其中 13 项专门验证备份与数据保护，另增加 1 项备份界面测试）。新旧 APK 签名验证通过，签名证书 SHA-256 均为 `77dcae457eff638df59d400554939c99423039435b7cc2b3789d6640f6d64a05`；包名不变、versionCode 从 3 增至 4，满足当前测试包覆盖安装的基本条件。

本批自动化覆盖备份往返、外部文件导出后回读、恢复后数据库重新打开、设置恢复、恢复点轮换、预览过期、数据库写入失败回滚、数据库提交后中断重试、恢复点创建失败、非法 ZIP/解压上限、未知结构保留以及旧答案并发写入保护。界面回归覆盖备份入口、大字号点击与原有学习/发音测试。

已检查备份设置页截图。测试在 Robolectric API 36 和文件数据库上执行；故障注入用异常模拟中断，不能代替手机上的真实断电或杀进程。实体机覆盖安装、Android 文件提供方、换机恢复和 API 24 仍需后续设备验收。备份数据层测试和结构身份检查不代表已经完成未来的 3 → 4 迁移测试。

系统自动备份规则尚未调整，当前仍沿用旧版配置。本批以应用内可验证的导出/恢复为主；正式签名迁移、系统备份规则及多词书存储继续按下一批推进。

## 手机验收建议

- 覆盖安装后核对当前词书、已练习数量和两个已学单词的复习状态，再先导出一份备份。
- 学习一个新词，再打开该备份的恢复预览并取消，确认新记录还在。
- 执行恢复，确认回到备份时的状态；再从本机恢复点恢复，确认刚才的新记录回来。
- 保持 Google TTS 为可用引擎，断网后试听并进入学习页发音。
- 外部备份文件保存在应用以外的位置；卸载/重装验证应在专用测试设备或已有多份已验证备份时进行。
