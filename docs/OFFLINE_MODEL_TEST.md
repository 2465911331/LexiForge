# MiniCPM5 内置模型测试版（1.0.12-test）

这版把 MiniCPM5-1B Q4_K_M 权重实际打进 APK，通过 llama.cpp 在 Android CPU 本机推理，不调用 AI API，也不启动本地 HTTP 服务。1B 是本次手机测试配置，未包含 2B。其他功能仍可按原方式联网导入词书、播放网络音频；这些功能与模型推理相互独立。

## 使用

1. 在旧版的备份恢复页面导出一份备份，然后直接覆盖安装本测试版。包名与原版相同，开发签名相同，现有学习记录保留。不要先卸载旧版。
2. 打开「单词」，点一个单词进入详情，下滑找到「离线学习助手 · 测试」。点击「使用离线助手」，选择释义解释、记忆提示或例句草稿，点击「生成草稿」。
3. 第一次会从安装包提取并校验模型，有进度提示。无需另行下载模型，第一次也可以完全断网进行。之后直接使用校验后的本地副本。
4. 可选择并复制生成的文字。点击「停止生成」可中断；切走页面、切词或进入后台也会停止，等待当前计算退出后释放模型内存。

## 手机与存储

- 仅包含 arm64-v8a 原生库，Android 7.0 及以上。编译使用 NDK r29，并使用 16 KB ELF/安装包对齐，面向 Android 16 兼容。
- 推荐 8 GB 及以上内存的设备。程序在可用内存低于约 1,200 MiB 或系统报告内存紧张时拒绝载入；此检查不能保证所有 ROM 上都不会被系统回收。
- 权重 688,065,920 字节（约 688 MB / 656 MiB）。APK 内保留一份，首次运行另存一份；安装及首次准备建议预留至少 3 GB 存储空间。
- CPU 推理使用 4 个线程、2,048 token 上下文、最多 256 个输出 token；120 秒触发停止，随后等待当前运算退出并释放内存。加载和计算需要时间，速度、发热及耗电以你的手机实测为准。
- 已提取的模型在 `noBackupFilesDir`，不会进入 Android 自动备份或应用的学习备份。学习备份仍然是原来的格式 5 / 数据库 6。清除应用数据或卸载会删除模型副本和本地学习数据；重新安装后的模型可重新从 APK 提取。

## 内容边界

生成内容标为学习草稿，仅临时显示，可复制，不自动保存，不修改词库、拆词、例句、考试数据、复习计划或评分依据。小模型会犯词性、释义、搭配和语法错误；开发机测试确实观察到错误解释，已收紧提示，但不能保证消除。助记联想不代表真实词源。释义解释只要求转述词典已提供的词性与义项。

首次准备及每次加载前校验 SHA-256；不完整、被改动或中断的模型副本不会进入推理。取消和页面退出会清理本次临时提取文件。中途被系统强制杀死可能留下 `.part`，下次准备会清理本程序产生的残留临时文件。

## 从源码构建

普通单元测试使用不带权重/原生库的配置，避免把大模型复制进测试资源：

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

源码包不重复装入 688 MB 权重或生成的 `.so`，构建脚本会从固定来源下载并校验权重和 llama.cpp。需要 Android SDK 36.1、JDK 21、Gradle 9.3.1、NDK r29（29.0.14206865）、CMake 3.31.6、Ninja 1.12.1；给下面参数填写各工具实际位置：

```powershell
.\scripts\build-offline-test.ps1 `
  -NdkPath 'D:\Android\Sdk\ndk\29.0.14206865' `
  -CMakePath 'D:\tools\cmake\bin\cmake.exe' `
  -NinjaPath 'D:\tools\ninja\ninja.exe'
```

可通过 `-GradlePath` 指定已有 Gradle，`-LlamaSourcePath` 指定该提交的已有源码；缓存齐全后加 `-Offline`。脚本构建 64 位安卓库，再用 `-PembeddedModel=true` 打包模型 APK。Gradle 也会检查模型大小、SHA-256 和原生库是否存在，缺失时中止构建。直接运行普通 `assembleDebug` 会生成不包含模型且不显示离线助手的轻量构建，不是本次交付的内置模型 APK。

开发签名沿用本机已有 debug.keystore，密钥不打进源码包。其他开发者使用自己的签名时不能直接覆盖当前已安装版本；请先导出备份，再自行决定是否卸载重装。
