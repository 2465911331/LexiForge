# LexiForge 1.0.7 离线分块学习版

覆盖安装本次同签名 APK，首次启动会自动匹配已有词书；**不需要卸载，也不需要重新下载词书**。原有单词 ID、学习状态、复习阶段和时间保留。修改内容前保存本机恢复点；仍建议保留个人导出的备份。

## 这次解决了什么

- 增加独立离线构词资料：词基不在当前词书时也可匹配；最多三层词族路径。
- 增加现代复合词表和普通拼写分块，后者不标为词根或音节。
- 新增多块排序练习，可撤回、清空、错误重试；重复块可以分别选择。
- 设置页、导入完成提示区分构词、拼写分块和整词，不把全部可分块词都当作构词覆盖。
- 资料、许可证、读音提示均打入 APK；无需 AI API 或模型。

## 使用入口

1. 安装后打开“设置 → 离线分块学习”，查看三类数量和离线资料许可。
2. 进入单词训练的“学习解析”，查看分块和来源；“构词资料分块”会显示词族路径。
3. 切换“拼写与构词”，按顺序选择字母块后提交。点击已选块可撤回，或清空重排。
4. 普通拼写分块会说明不是词根/音节；CMUdict 音节提示只代表词典首个美式读音。播放声音继续使用当前 TTS/发音设置。

## 数据边界

资料库经过词性、可用词缀、词基词典、字形、歧义与例外过滤。例如 `butter → butt + er`、`peer → pee + er` 已排除。尚未逐词人工审校，不能把词族关系直接当作释义，发现疑点需继续维护例外或补充人工解析。

短词、资料未收录词和不宜可靠拆分的词继续整词练习；不会为提高覆盖率随意切字母。词频仍未分级。多词书并存尚未实现，切换词书仍遵循现有替换与恢复点提示。
