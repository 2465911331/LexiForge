# LexiForge 1.0.8：多词书与学习记录

版本：1.0.8（versionCode 9），2026-10-05，开发预览版。

## 安装与升级

使用本次 APK 覆盖安装此前同签名的开发版，保留应用数据。不要先卸载。可以先在旧版“设置 → 备份与恢复”导出一份备份，作为应用之外的副本。

本版沿用此前的调试签名，不是正式发布签名。数据库从版本 3 迁移到 4：先保存并校验旧词书和进度的本机恢复点，再在事务内升级结构。恢复点保存失败会阻止迁移；缺少迁移路径不会自动清库。不能把旧 APK 直接覆盖到新版数据库上作为降级方法。

## 我的词书

- 在“设置 → 我的词书”添加四级、六级或其他已有来源的词书。首次下载需要网络，已下载词书可离线切换。
- 添加词书保留原有词书。再次选择已经下载的词书只切换，不重新导入或重置。
- 每本词书分别保留单词与词根卡片的复习阶段、期限及最后选中的单词；重新进入单词训练可继续上次位置。
- 同拼写词条不自动共享进度，避免不同词义、不同来源互相覆盖。经核实的跨词书共享、跨书汇总队列和每日计划仍未实现。
- “重置当前词书进度”只重置当前书的复习状态，其他词书与历史作答保留；重置前保存恢复点。

## 作答记录

入口：“设置 → 学习记录 → 查看作答记录”。界面显示当前词书最近 100 条和总数；本机保存全部记录，导出备份包含全部记录。

记录范围：整词拼写、分块排序、构词选择、词根卡片自评。每条保存题目、实际提交的答案、对错、自评结果、作答时间、耗时、尝试次数、使用过的解析或选项等辅助、关联重试，以及复习阶段是否改变。

读音标记表示点击了播放按钮，不表示语音一定播放成功。词根卡片的“认识”是用户自评；使用选项和看过解析的答案会标明辅助，不能直接等同于无提示回忆。

重复点击同一次提交不会重复记账。修改答案后的重试独立记录。提前练习和即时纠正可以产生记录，但不会因此连续提升复习阶段。答案和进度在同一事务中保存；任一写入失败均回滚，界面提示重试。

详细历史从升级后开始。旧版只保留的学习阶段和时间继续有效，但无法重建此前每一道题的真实答案。本版沿用原来的固定间隔复习规则，没有切换到新的记忆算法。

## 备份与恢复

新版备份覆盖全部已下载词书、各书进度、最后学习位置、当前词书、作答历史和现有受支持的学习设置。导出仍使用 `.lexiforge-backup` 文件，文件未加密，请自行保管。

恢复前显示词书数量、词数、作答数量和当前词书。确认恢复会替换整个本地词书库，不是合并；先为现状保存恢复点。恢复中断会在下次启动继续，完成校验后才能学习。

备份格式为 2，最低读取版本为 2；应用 1.0.8 能读取以前格式 1 的单词书备份。旧版应用不能读取新的多词书备份。恢复旧单书备份也会替换整个当前库，应先检查预览。

当前保护上限：20 本词书、合计 100,000 个词条、100,000 个组件和 100,000 条作答事件；超限会明确拒绝备份或导入，不静默截断。后续可在有实际数据规模需求时升级格式和分页导出。系统 TTS 引擎、系统语音包、APK 本身不包含在学习备份中。

## 验证与边界

完整自动化测试 108 项全部通过（无失败、无跳过），调试 APK 构建成功。已检查词书管理浅色界面与作答记录深色界面的截图。

自动化覆盖真实四级 4,544 词与六级 3,992 词并存、备份往返、同 ID 不同词义隔离、独立进度与位置、重复导入、真实版本 3 数据库迁移、迁移前备份失败保护、恢复中断续作、答案与进度原子写入、重复提交、提示与重试，以及词书切换和记录界面。

核心学习仍在本地运行，不调用 AI API，不下载或内置新模型。本次没有更换发音实现、图标或内容解析包。

自动化与模拟环境不能替代实体设备测试。尚未在一加 Ace 2 Pro / ColorOS 16 上实测本版覆盖安装；建议设备验收顺序为：覆盖安装 → 检查原进度 → 添加另一词书 → 断网切换两书 → 各答一题 → 查看记录 → 导出备份。
