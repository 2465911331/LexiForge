# UI 改版：学习入口、列表与设置

## 信息结构

- 底部导航：今日、单词、设置。训练和词根库作为次级页面，隐藏底部导航，返回原入口。
- 今日：当前词书、到期单词数、词书内未学数、主学习按钮、词根卡片与词根库、累计练习进度。
- 单词：搜索、全部／未学／待复习／已练习筛选、简洁条目；详情单独显示释义、构词提示和有效例句。
- 设置：词书、外观、发音、学习数据。词书与语音引擎通过对话框选择。

## 操作与显示约定

- 首页主按钮有到期单词时打开仅到期队列；没有到期任务时打开学习队列。学习队列允许新词和到期词，保留到期优先顺序；按钮不暗示已经实现每日目标。
- 每次显式开启训练会清除旧词频筛选，避免首页数量与实际可练习队列不一致。词根卡片入口明确进入词根练习，不再按时段自动选择。
- 列表筛选独立于训练范围；搜索忽略大小写与首尾空格。离开列表进入训练后，返回保留详情、搜索和筛选。
- 到期数量和状态随时钟更新；答错后的单词也会按时间进入待复习。“已练习”与“待复习”可能重叠，它们不是互斥的掌握等级。
- 累计练习以有作答时间为依据，包含答错，不称为掌握率。显示数量和进度条，避免少量练习被取整为 0%。
- 暂不展示旧七日图表：现有数据不能准确还原每天学习事件。未添加虚构的每日完成量、连续打卡或学习目标。
- 列表不展示未经核实的词频标签。占位式英文句子不再作为例句显示。
- 练习标签改为“学习解析”和“拼写与构词”；练习页顶部隐藏目标拼写，例句中遮盖目标词。构词练习仍含组件选项，不宣称等同完全无提示回忆。
- 清空进度与替换词书均需单独确认。当前替换词书仍会重置进度，确认文案明确说明；本批没有实现多词书保存、备份或通用数据库迁移。
- 列表发音使用单个可释放播放器，切换单词／离开列表时清理；在线失败尝试设备语音，无法播放时给出提示。实际网络与设备语音需真机验证。
