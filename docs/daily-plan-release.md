# LexiForge 1.0.9：每日学习计划

版本：1.0.9（versionCode 10），2026-10-05，开发预览版。

## 使用

覆盖安装后，在首页“今日学习”查看当前词书的每日计划。点击“调整每日目标”，可以选择只复习、10、20、30、50 词，也可输入 0～200 的整数。默认每天 20 个新词，每本词书独立保存目标。

“开始今日学习”优先安排当前到期复习，再继续已经开始但未答对的新词，最后补足今日新词配额。词书剩余新词不足时，只安排实际可学数量。词根部件卡片仍是独立练习，不混入单词数量。

## 计数规则

- 首次提交答案时记为“已开始”，答对后才计入“今日新词已完成”。首次答错会占用一个新词名额，继续练习答对即可完成，重试不重复计数。
- 看解析、打开词条或播放读音不会单独计为完成。拼写、构词选择、分块排序都可完成新词，但“完成”不等同于无提示掌握；使用的辅助仍保存在作答记录中。
- 从单词列表自由练习的新词同样计入今日进度。自由练习允许超出计划目标，不阻止主动加练；首页会按真实已开始数量显示。
- 到期复习没有人为上限。今日已复习数量按旧词去重；同一词稍后再次到期，仍会回到任务队列。提前自由练习不增加“已复习旧词”数量。
- 保存目标后今天立即生效。调低目标不会抹去已经开始的词或真实完成量；已经开始但未答对的词仍需完成。
- 每天按手机本地日期更新，包括跨月、夏令时和切换时区。应用重新打开时依据数据库记录重算，不依赖后台定时器。改变系统日期或时区也会改变“今天”的统计范围。
- 重置学习进度仍保留作答历史，所以不会删除当天已发生的学习记录或重置每日目标。它不是“清空今天的计划”。

## 升级与备份

使用本次 APK 覆盖安装同签名旧版，不要先卸载。数据库显式迁移到版本 5；从 1.0.8 升级前保存包含全部词书和作答历史的恢复点，旧进度、学习位置和历史保持。保存恢复点失败会阻止升级，不自动清库。

旧版历史没有可靠的首次学习标记，不会猜测哪些历史答案属于新词。本版开始保存标记后，今日新词与已复习旧词的统计才能准确累积；旧版学习进度继续影响到期任务。

每日目标和首次学习标记随全库备份保存。新备份格式为 3，需要 1.0.9 或更新版本读取；本版兼容格式 1 和 2 的旧备份，旧备份恢复后的每日目标默认为 20。恢复仍是替换整个本地词书库，不是合并。

本版保持离线核心学习，不调用 AI API。尚未加入通知提醒、考试倒计时、固定截止日期或新的记忆调度算法。
